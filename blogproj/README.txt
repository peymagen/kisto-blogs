Kisto Sons Blog - Formatted Demo

Open index.html in VS Code / Chrome.

Files:
- index.html -> blog listing page
- blogs/ -> 10 individual article pages
- assets/blog.css -> formatted responsive CSS
- assets/blog.js -> scroll progress + share/copy functionality

IMAGE INSERTION:
The demo uses real property images for four selected blog cards and their article hero sections; the remaining demo placeholders are unchanged.
To use real images, put image files inside assets/images/ and replace a placeholder, for example:

<div class="fakeimg g1">PROJECTS</div>

with:

<img src="assets/images/project-1.jpg" alt="Project image" class="blog-image">

For article pages, use the same idea with a relative path such as:

<img src="../assets/images/project-1.jpg" alt="Project image" class="hero-image">

Replace demo facts with verified Kisto Sons property/project data before publishing.
